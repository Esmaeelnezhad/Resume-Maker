# رزومه‌ساز

یک رزومه‌ساز فارسی و انگلیسی، سریع و حریم‌خصوصی‌محور. همه اطلاعات داخل مرورگر کاربر می‌ماند و برای ساخت رزومه نیازی به حساب کاربری نیست.

## قابلیت‌ها

- ویرایش زنده مشخصات، سوابق کاری، تحصیلات، پروژه‌ها، مهارت‌ها و زبان‌ها
- دو قالب مدرن و کلاسیک با رنگ، فونت، فاصله‌گذاری و جهت متن قابل تنظیم
- پشتیبانی کامل از رزومه‌های راست‌به‌چپ و چپ‌به‌راست
- افزودن عکس پروفایل با کنترل نوع و حجم فایل
- ذخیره خودکار روی دستگاه
- دریافت و بازیابی نسخه پشتیبان JSON
- خروجی PDF استاندارد A4 از طریق چاپ مرورگر
- طراحی واکنش‌گرا و دسترس‌پذیر

## اجرای محلی

به Node.js 22.13 یا جدیدتر نیاز است.

```bash
npm ci
npm run dev
```

سپس آدرس نمایش‌داده‌شده در ترمینال را باز کنید.

## بررسی نسخه تولید

```bash
npm test
```

## حریم خصوصی

اطلاعات رزومه در `localStorage` همان مرورگر ذخیره می‌شود. پاک‌کردن داده‌های مرورگر، اطلاعات ذخیره‌شده را حذف می‌کند؛ برای نگهداری بلندمدت از گزینه «دریافت پشتیبان» استفاده کنید.
